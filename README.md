# 🛍️ Shop-Django

A **Django learning project** built to practice **Django** and **Django REST Framework (DRF)**.  
Although developed mainly for educational purposes, the project includes real-world features like authentication, email verification, shopping cart, and payment integration.

---

## 🚀 Features
- User authentication using **Simple Auth Token**
- Email verification system
- Shopping cart functionality
- Payment gateway integration
- Mostly static pages (not API-focused)
- Clean and modular code structure

---

## 🛠️ Tech Stack
- **Python 3**
- **Django** & **Django REST Framework**
- **SQLite** (default, can be replaced with PostgreSQL/MySQL)
- **Virtualenv** for environment isolation

---

## ⚙️ Installation & Setup

Clone the repository:

    git clone https://github.com/1ArsalanAmiri/shop-django.git
    cd shop-django

Create and activate virtual environment:

    python -m venv venv
    # Windows
    venv\Scripts\activate
    # Linux/Mac
    source venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

Run migrations:

    python manage.py migrate

Start development server:

    python manage.py runserver
